# 隐私与数据处理

适用于 Windows v1.9 与 Mac v2.4.1。不同平台的凭证保存方式有所区别。

## 本机接入

接入用于本人有权访问的微信账号和电脑已同步的记录。Windows 的接入材料使用当前 Windows 用户的 DPAPI 加密保存。

Mac 凭证保存在当前 macOS 用户的钥匙串中，不同项目可能共用同一凭证项。接入创建单独的微信副本，不覆盖原 App，原聊天数据库只读。聊天缓存和报告保存在所选项目目录。

解密缓存、选定范围的聊天素材和生成报告可能在本机以明文形式保存。密钥加密不等于所有文件均被加密；本机管理员仍可能访问相关文件。

## Agent 与模型

技能安装只部署使用说明并检查环境，不授权读取全部聊天。

用户请求生成某个群的报告时，Agent 按群和时间范围读取素材。使用云端 Agent 意味着这些素材会交给所用服务处理，具体数据政策取决于该服务。

Windows 定时摘要默认采用本地规则。云端自动增强及 Ollama 接入尚未完成，不应当作当前可直接开启的功能。

## 手机推送

用户选择绑定并启用后，报告或摘要会经过相应微信通道发送到本人手机。未启用推送时，不因生成日报而自动发送。

## 公开反馈

本仓库不收集或存储用户聊天数据库、密钥和推送凭证。不要通过 Issues、公开评论或仓库附件上传这些资料。

问题截图、诊断与报告也可能包含个人信息，公开前需要检查并移除。这个说明不替代 Agent 服务或微信通道各自的数据政策。
