微信 AI 助手 · Mac v2.4.1

安装好助手，开始整理群聊

接入你自己的微信，按群聊和时间范围整理重点、待办与链接。报告可保存到本机，也可按需推送到本人手机或设置定时摘要。

首次接入在 App 内完成。之后的群聊总结、推送与定时摘要，通过你使用的 AI 助手（Agent）配置。

开始前准备

  • Apple Silicon（M 系列芯片、arm64）Mac，macOS 14 或更新版本。本安装包不适用于 Intel Mac。
  • 将自己的 Mac 微信安装在“应用程序”，路径应为 /Applications/WeChat.app。
  • 为本机项目留出保存微信副本、聊天缓存与报告的空间。Python、Node 和基础运行组件已随包提供。

五步开始使用

  1. 安装并打开 App

    打开安装镜像，将“微信AI助手.app”拖入“Applications（应用程序）”。复制完成后，从“应用程序”打开助手。

    请先确认来源可信。App 使用本机签名（ad-hoc），未使用 Apple 开发者身份签名，也未经过 Apple 公证。若 macOS 阻止打开，保留具体提示供排查，不删除隔离属性、不关闭 Gatekeeper 或降低全局安全设置。

  2. 准备本机项目

    点击“准备本机项目”，按窗口提示确认保存配置与资料的工作文件夹。默认位置为：

    ~/Library/Application Support/WeChatAIAssistant/Project

    项目需要位于本机可写的位置。准备项目时不会读取微信聊天。已有项目可通过“选择已有项目”打开，具体方法见本页的已有项目说明。

  3. 查看计划，再确认接入

    先保存微信里未发送的内容。确认当前项目后，点击“开始首次接入”，查看只读计划；此时不会读取聊天正文或钥匙串，也不会获取解密凭据或解密聊天数据。

    核对微信版本、微信副本位置和数据访问程序，点击“确认计划并继续”。在 App 原生确认框“确认开始首次接入？”中阅读影响，再选择“确认并开始”。点击“取消”则不启动任务。

    这一步需要你授权：任务会创建并重新签名微信副本，按需退出并启动微信，使用临时 Hook（短暂访问微信进程）取得本机解密凭据，将凭据保存到当前 macOS 用户的钥匙串，并生成本地明文聊天副本。原微信数据只读，原版微信不被覆盖，也不复用或覆盖同版本既有副本。临时 Hook 与副本重签名并非微信官方接入方式，可能受客户端更新或安全策略影响。

    手机登录确认与 macOS 授权由你本人完成；微信显示二维码时再扫码。密码只在 macOS 系统窗口输入。退出目标不明确、账号无法唯一识别或必要授权未完成时，任务会停止并提示。数据访问授权请核对计划列出的 WeChatDataBridge.app 完整路径，不向 Agent 提供密码、密钥或推送令牌。

  4. 查看接入结果

    App 会显示任务进度和结果。需要停止时，点击“取消本次接入”并等待结束。App 会尽力恢复本次改动或保留备份，不保证完全回滚，也不会自动重新打开原微信；必要时请自行打开原版微信。

    状态暂时不可用时点击“重新检查状态”。失败或取消后，先看恢复提示，再点击“重新查看接入计划”。保留已有资料和备份，避免连续重复操作。

    已有缓存可读不代表当前微信的所有消息都已同步。生成报告前，请确认目标群、日期的数据范围与更新时间；辅助索引暂时无法检查时，按界面提示处理。

  5. 生成你的第一份群聊总结

    接入完成后点击“查看群日报功能”，在功能页复制请求，粘贴到可访问本机项目的 Agent。告诉它准确群名、日期或起止时间、时区，以及是否允许云端 AI 处理聊天内容。

    示例：请整理产品交流群今天的重点、待办和有用链接，先确认群名与时间范围，再保存到本机。

    同名群需要先确认准确对象。报告可保存为文本、HTML 或 PNG；生成 PNG 需要本机已有 Chrome、Chromium 或 Edge，没有浏览器时可先保存文本或 HTML。

按需配置推送与定时摘要

功能怎样开始
微信推送在对应功能页复制请求交给 Agent，绑定本人 ClawBot、准备会话，并确认发送给自己的具体内容。推送组件已随包提供，绑定信息由你配置。
定时摘要复制请求交给 Agent，确认群聊范围、执行间隔、是否推送到本人手机，以及是否使用本地模型。配置后核对任务状态和停用方法。
本地模型增强选择使用本地模型整理摘要时，另行安装 Ollama 并下载模型。下载前确认所需空间和处理方式。

复制请求后仍需交给 Agent 执行。安装 App、准备项目和首次接入不会自动发送消息、启用定时任务或下载模型。

隐私与安全

你的资料保存在哪里

账号配置、聊天缓存和报告保存在当前选择的本机项目中。聊天缓存为明文副本，报告也可能含私人信息，请谨慎分享和授权文件访问。安装包不含他人的账号、聊天记录、密钥或推送凭据。

凭据与授权

解密凭据保存在当前 macOS 用户的钥匙串，不同项目共用该凭据项。接入期间可能产生仅当前用户可访问的临时凭据文件，任务结束时执行清理。微信手机登录确认、macOS 数据访问和调试授权由你本人完成；请核对 App 列出的完整路径，密码只在 macOS 系统窗口输入。

本地或云端处理

首次接入在本机执行。后续选择云端 Agent 时，你提供的聊天素材会由相应服务处理。请先确认群聊、时间范围和允许的处理方式；只需本地处理时，先由 Agent 确认可用方案。数据库、解密密钥、系统密码和推送令牌不应上传给 Agent、写入公开报告或分享给他人。

生成报告前应核对数据范围和更新时间；资料缺失不等于没有消息。发送、定时任务和模型下载按你单独确认的对象、内容与设置执行，复制请求本身不会执行这些操作。

常见问题

找不到微信或无法继续接入

确认微信位于 /Applications/WeChat.app，再查看 App 中需要先处理的事项。微信版本或项目变化后，请重新查看接入计划。

接入停在登录或授权

查看微信和 macOS 的实际提示，核对授权对象后由本人处理。拒绝授权或目标无法确认时任务会停止；先看结果，不连续重复接入。

日报没有预期内容

核对准确群名、日期、时区、数据范围与更新时间。资料缺失或尚未更新时，先处理资料问题，不能当作当天没有消息。

手机没有收到推送

先核对本人绑定与会话状态，再请 Agent 检查发送结果和手机实际收件情况。保留本机报告，避免重复推送。

需要协助排查

保留 App 的具体失败提示，复制排查请求交给 Agent。需要诊断文件时，点击“导出诊断包”，再选择“保存脱敏诊断”。先检查状态；不要把系统密码、密钥、推送令牌或聊天正文放进诊断截图。

已有项目如何继续使用

打开原来的项目

先退出正在运行的助手，再打开 v2.4.1。不要同时运行两版助手，也不要用旧版写入已经更新的同一个项目。点击“选择已有项目”，选中完整项目文件夹，再点击“复用此项目”，并核对界面显示的路径。

按提示更新项目程序

看到“已就绪”即可继续使用。看到待升级提示时，先阅读将更新的文件列表，再点击“更新项目程序”，在“确认更新本机项目？”窗口中选择“确认升级”。助手会先备份，再更新自带的程序和说明；账号配置、聊天缓存、凭据、报告和未知的自定义文件不在替换范围内。

完成后点击“重新检查项目版本”，确认已就绪。程序更新本身不需要重新接入微信，也不会发送消息或启用定时任务。

出现冲突或需要恢复

有文件冲突时，“保留自定义，暂不升级”会保留当前文件并暂停该项目的接入与功能请求；“备份冲突并升级”会在再次确认后保留原件，再使用新版，自定义修改不会自动合并。备份失败时会停止更新。

更新中可点击“取消项目升级”，并等待实际结果。看到未完成升级提示时，点击“恢复未完成升级”，在“确认恢复未完成升级？”窗口中审阅后选择“从备份恢复”，恢复后重新检查项目版本。保留 App 显示的备份位置和提示，不手动删除备份或覆盖整个项目；需要帮助时按本页常见问题保存脱敏诊断。
