# Windows 安装与使用

目标环境为 Windows 10 / 11 x64、电脑端微信 4.x；微信小版本兼容性仍需在实际电脑确认。

## 1. 打开程序

1. 从 Windows 对应 Release 下载 ZIP，将整个压缩包解压到一个文件夹。
2. 打开电脑微信，登录要使用的账号。
3. 双击根目录的 **微信AI助手.exe**。

保留包内“程序”和“运行环境”文件夹，不要只复制启动入口。缺少 WebView2 时，启动入口会提示安装随包的微软离线运行库。

## 2. 完成微信解密

程序先检查环境与数据目录。确认显示的位置与微信设置一致，再点击“同意并开始解密”。微信可能关闭并重新打开，由你本人完成登录，登录后程序自动继续。

如果微信没有自动打开，请手动打开并登录。等待显示“已保存微信接入设置”，再继续安装群聊技能。

### 没有找到目录，或发现多个位置

在电脑微信中打开：**左下角菜单 → 设置 → 存储位置**。

查看当前路径，在工具主页面点击“选择目录”，选中对应位置。选择后自动检查并记住有效位置，无需再点检测账号。

请选择微信设置里的当前位置，不是微信程序的安装目录，也不是以前的备份文件夹。不同微信版本的设置名称可能略有不同。

## 3. 安装群聊技能

进入“群聊总结/日报”，点击“复制技能安装指令”，粘贴给你常用的 Agent。

Agent 需要能够访问这台电脑的文件、调用本机程序，并支持对应技能机制，例如具有本机访问能力的 WorkBuddy 或 Codex。仅网页聊天环境不能直接读取电脑微信数据。是否需要新建对话，以实际安装结果为准。

安装后直接说：

> 生成“XXX群”今天的日报。

默认输出 PNG，同时保留 HTML、Markdown。多群分别生成，不混在一份报告里。首次使用时，Agent 应先核对数据覆盖范围和读取状态。

PNG 需要本机已有可用的 Edge 或 Chrome。未能生成图片时，应保留 HTML / Markdown 并说明原因。

## 4. 可选功能

**微信推送：** 在对应页面复制配置指令给 Agent，完成绑定与手机收件确认。可按需发送报告图片、MD 或 HTML 附件。WorkBuddy 优先采用其原生通道；其他 Agent 可使用独立 ClawBot，实际启用以安装与验收结果为准。

**定时摘要：** 默认关闭。配置推送后，再按页面指令由 Agent 完成预览、测试和任务注册。默认每小时一次，可直接告诉 Agent 改成 30 分钟或两小时。

定时摘要默认采用本地规则，固定展示“🚨 待你处理 / 📌 你需知道 / 👥 群聊摘要”。云端模型增强和本地 Ollama 尚未自动接入。

电脑需开机、联网、保持当前用户登录，电脑微信需正常同步。面板不需要常驻；定时任务和独立连接组件根据启用的功能运行。

独立 ClawBot 上下文过期时，在手机给已绑定的 ClawBot 发一条消息，再观察下一次推送；仍未恢复时让 Agent 查状态，不承诺发一条消息就必然恢复。不使用键盘模拟或文件传输助手兜底。

## 出现问题

点击窗口底部“遇到问题”，复制排查请求给能访问本机的 Agent。无需先完成解密或安装群聊技能。结果未知时先排查，不连续重复取钥。

启动入口打不开时，查看 ZIP 中的“遇到问题怎么办.md”。公开反馈前检查诊断和截图，不提交个人聊天或接入凭证。
