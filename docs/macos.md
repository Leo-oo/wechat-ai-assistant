# Mac 安装与使用

需要 **macOS 14 或更高版本、Apple Silicon（M 系列）芯片**，不支持 Intel Mac。

[下载安装包](https://github.com/Leo-oo/wechat-ai-assistant/releases/tag/macos-v2.4.1) · [常见问题](faq.md)

## 1. 安装并准备本机项目

1. 打开 DMG，将 **微信AI助手.app** 拖到“应用程序”。
2. 从“应用程序”打开 App。电脑微信应位于 `/Applications/WeChat.app`。
3. 点击 **准备本机项目**，选择可写的本地目录；或选择已有项目并点击 **复用此项目**。

默认项目位置是 `~/Library/Application Support/WeChatAIAssistant/Project`。Python、Node 和基础运行环境已随包提供，不需要自行配置。准备项目本身不会读取聊天。

App 使用 ad-hoc 签名，未经过 Apple 开发者签名和公证。如果系统阻止打开，请保留完整提示，让能够访问本机的 Agent 协助检查；不要直接移除隔离属性或关闭 Gatekeeper。

## 2. 首次接入微信记录

1. 点击 **开始首次接入**，先查看只读接入计划。此时尚未取钥或解密。
2. 核对微信版本、副本位置和桥接组件信息，点击 **确认计划并继续**。
3. 在原生确认窗口中点击 **确认并开始**，再按提示完成微信登录、扫码和系统授权。
4. 等待程序检查读取状态。缓存可读不代表所有最新消息已同步，生成报告时仍需核对时间覆盖。

接入会创建并重新签名单独的微信副本，在必要时退出、启动微信，临时获取本机解密凭证。**原微信 App 不被覆盖，原聊天数据库只读。** 已存在的同版本副本不会被静默覆盖。

密码、扫码和权限确认由本人完成。系统提示涉及桥接组件时，先核对 `WeChatDataBridge.app` 的实际路径；账号或路径不明确时先停止检查。

### 中途取消或失败

点击“取消本次接入”后等待操作结束，再查看恢复提示、点击“重新检查状态”。程序会尝试清理与恢复，但不能保证所有外部状态都能自动还原；原微信可能需要手动打开。

先核对接入和清理状态，再重新查看计划，不要连续重复取钥。可使用 **导出诊断包 → 保存脱敏诊断**，将必要信息交给 Agent 排查；公开发送前再检查一次个人信息。

## 3. 安装群日报技能

接入完成后，点击 **查看群日报功能**，将安装请求复制给支持访问本机文件、执行程序和技能机制的 Agent。

安装完成后直接说：

> 生成“XXX群”今天的日报，默认输出图片，同时保留 HTML 和 Markdown。

Agent 应先核对群名 / 群 ID、日期、时区、素材覆盖和读取状态；同名群不能直接猜选。使用云端模型前，明确本次所选素材会交由该服务处理。

生成 PNG 需要本机可用的 Chrome / Chromium / Edge。图片生成失败时保留文字和 HTML，并说明原因。

## 4. 可选：微信推送与定时摘要

**微信推送：** 复制对应请求给 Agent，按指引绑定本人 ClawBot、准备会话并确认发送内容。绑定完成不等于自动发送全部报告。

**定时摘要：** 复制对应请求给 Agent，确定读取范围、频率和推送方式，确认手机收到测试内容后再启用。让 Agent 同时告知任务状态与停止方法。

**本地模型：** 如需 Ollama，由 Agent 按安装指南检查空间、安装服务并配置模型。App 不会自动下载模型；是否可用以实际检查与测试为准。

安装 App、准备项目和首次接入都不会自动发送微信消息、注册定时任务或下载模型。

## 5. 复用已有项目与升级

1. 关闭旧版 App，避免两个版本同时写入同一项目。
2. 在新版选择已有项目，点击 **复用此项目**，核对目录。
3. 如提示程序更新，先查看更新清单，再选择 **更新项目程序 → 确认升级**。
4. 更新完成后重新检查项目版本。仅更新程序通常不需要重新接入，也不会自动开启推送或任务。

升级前会备份，保留账号配置、缓存、凭证引用、报告和未知自定义文件。遇到冲突可暂不升级；确认后才备份冲突文件并更新，不自动合并。备份失败时停止；升级取消或恢复未完成时，先按恢复提示处理。

## 本机数据在哪里

聊天解密缓存和报告保存在你选择的本机项目中，可能含明文聊天，请妥善保管。凭证保存在当前 macOS 用户的钥匙串中，不同项目可能共用同一凭证项；不要把删除单个项目当作删除凭证。

使用云端 Agent 整理时，指定范围的聊天内容会交由该服务处理。更多说明见 [隐私与数据处理](privacy.md)。
