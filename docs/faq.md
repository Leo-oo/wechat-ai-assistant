# 常见问题

## 需要把程序面板一直开着吗？

Windows 完成接入和技能安装后，日常群聊总结由 Agent 按需调用本机程序，面板可以关闭。电脑微信需要正常同步。开启定时摘要后，相关任务与连接组件按配置在后台运行，关闭面板不等于暂停摘要。

## 为什么聊天在本地，整理时还会使用云端？

本地读取与模型整理是两个步骤。使用云端 Agent 时，指定范围的素材会交给它处理。如果希望仅本地整理，需要已验证的本地模型或规则流程，不能把云端 Agent 称为全程本地。

## 生成日报会自动发到手机吗？

默认保存在电脑。绑定微信推送后，也需要明确要求发送报告；定时摘要则在完成配置并启用后按频率推送。

## 手机能打开哪些格式？

Windows 独立通道的 PNG、MD、HTML 已在开发者手机完成收件测试。图片查看、附件下载与手机直接预览是不同能力，手机和微信版本可能影响附件打开方式。每位新用户仍需确认自己的手机收件情况。

## 是所有 Agent 都能直接使用吗？

需要 Agent 支持本机文件访问、执行程序和相应技能机制。Agent 的名称本身不代表具备这些能力。安装时以实际检测结果为准。

## 能分析图片、语音和视频正文吗？

Windows v1.9 主要处理可读文字与元信息，尚未自动分析语音、图片、视频和文件正文。报告应说明覆盖缺项。Mac 的能力范围以对应发行资料为准。

## 下载页面的 Source code 是安装包吗？

不是。它是 GitHub 自动提供的说明仓库快照，请选择 Release 中明确标注的平台部署包。

## Mac 支持哪些电脑？

Mac v2.4.1 要求 macOS 14 及以上、Apple Silicon（M 系列）芯片，不支持 Intel。电脑微信应安装在 `/Applications/WeChat.app`。完整步骤见 [Mac 安装指南](macos.md)。

## Mac 提示无法打开怎么办？

当前 App 使用 ad-hoc 签名，未经过 Apple 开发者签名和公证。保留系统提示并让 Agent 检查，不直接关闭 Gatekeeper 或移除隔离属性。接入中遇到问题可导出脱敏诊断，先检查状态，不连续重复取钥。

## Mac 更新程序要重新接入吗？

通常不需要。新版选择已有项目并复用，核对路径后按提示更新项目程序。升级前备份，遇到自定义文件冲突先确认；不要让两个版本同时写入同一项目。

## 可以把手机消息作为指令发给 Agent 吗？

当前 Windows 独立通道只用于接收推送，不提供通过手机控制 Agent 的双向能力。WorkBuddy 自身通道的能力由它提供，不能等同于本项目的独立通道。

## 可以上传日志让大家帮忙吗？

先检查内容，移除聊天正文、联系人、账号标识、二维码、密钥、令牌和个人路径。不要上传整个微信数据目录。优先使用程序的脱敏诊断，并确认附件中确实没有个人信息。
